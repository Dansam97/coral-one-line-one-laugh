Entry for the make.fun bounty "One Line, One Laugh": a single one-liner of at most 200 characters, written by `main.py` to `/output/entry.txt`. A fortune teller studies a palm, goes completely silent, and offers a refund and a hug — the joke turns on the ending. The program self-checks the line against the gate (UTF-8, 1–200 characters) before writing it.

## Run it

```sh
python3 main.py
```
